# AI Usage

This project used AI assistance as a programming support tool while I developed VantaBlade.

## How AI Was Used

AI was used to help with:

- Explaining Python, pygame, state machines, inheritance, saving systems, and collision logic.
- Brainstorming and planning features such as bosses, upgrades, keybinds, level progression, and movement mechanics.
- Refining code for systems such as state management, boss structure, saving, HUD feedback, particles, and settings.
- Debugging errors by reviewing code, explaining likely causes, and suggesting possible fixes.
- Reviewing and improving comments, explanations, and documentation so the code is easier to understand.
- Generating clearer commit messages.

## My Role

- I chose the game design, features, controls, levels, and final gameplay behavior.
- I wrote the core code myself.
- I reviewed and tested code before adding it to the project.
- I playtested the game and made changes based on what worked best.
- I asked for explanations of major systems so I could understand and defend the code.
- I made the final decisions about what stayed in the project.

## AI Tool Used

- OpenAI ChatGPT / Codex was used as the AI programming assistant.

## Note

AI was used as a helper, not as a replacement for understanding the project. It did not complete the project for me or act as an employee coding the game independently. The final project structure, gameplay choices, and code were reviewed, tested, and accepted by me.
